# FitCrew V3

## 中文

V3 是建立在当前 V2 健康数据与隐私基础之上的决策与学习层。

请先阅读根目录的 `AGENTS.md`。

### 核心信息架构

今天（Today）、旅程（Journey）、实验（Experiments）、记录（Log）、我的（Profile）。

### 核心用户循环

观察 → 提出假设 → 推荐 → 用户行动 → 测量 → 评估 → 学习 → 下一步行动。

### 长期结构

90 天旅程 → 每周实验 → 今日任务 → 此刻行动。

### 重要说明

不要创建一套并行的 V3 健康数据技术栈。复用当前 V2 基础设施。

请参阅 `DESIGN.md`、`USER_TIPS.md`、`../agent-context/ARCHITECTURE_BASELINE.md` 和 `../agent-context/V3_DATA_MODEL.md`。

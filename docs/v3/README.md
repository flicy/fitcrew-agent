# FitCrew V3

V3 is the Decision & Learning Layer built on the current V2 health-data and privacy foundation.

Read root `AGENTS.md` first.

## Core information architecture

```text
Today
Journey
Experiments

```

## Core user loop

```text
Observe
→ Hypothesize
→ Recommend
→ User Action
→ Measure
→ Evaluate
→ Learn
→ Next Action
```

## Long-horizon structure

```text
90 Day Journey
→ Weekly Experiment
→ Today Mission
→ Right Now Action
```

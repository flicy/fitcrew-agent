# FitCrew V3 User Tips

## V3 有什么新变化

V3 会开始真正记住你的长期变化。

### Today

每天先告诉你：

“今天最值得做什么。”

### Journey

把 InBody、训练、睡眠、活动、VO₂ Max、血糖和主观感受放进一条 90 天身体旅程。

### Experiments

AI 可以和你一起跑一个小实验。

例如：

Sleep Reset。

连续一周睡够之后，再看 HRV、静息心率和精力有没有改善。

### InBody

不只看体重。

长期看：

- 体脂
- 脂肪量
- 骨骼肌
- 去脂体重

### Meal Photo

一张餐食照片可以和：

- CGM
- workout
- sleep
- fullness
- energy

一起成为你的身体记忆。

### Body Check

数据之外，也记录：

“你真实感觉怎么样。”

## V3 一句话

V1 陪你做。

V2 理解你的数据。

V3 帮你决定下一步，并从结果里继续学习。

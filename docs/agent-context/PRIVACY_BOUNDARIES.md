# Privacy Boundaries

## 中文

### 核心规则

群聊上下文与私人 BodyOS 上下文保持分离。

### 群聊可以包含

- 共享专家知识
- 公开打卡
- 公开挑战
- 用户明确分享的完成结果

### 私人 BodyOS 可以包含

- Apple Health 派生指标
- 连续血糖监测（CGM）
- 心率变异性（HRV）
- 睡眠
- InBody 身体成分数据
- 餐食事件（Meal Event）
- 身体感受记录（Body Check）
- 实验
- 个人身体模型（Personal Body Model）

### 绝不提交真实健康证据

不得提交真实 HealthKit 导出、真实血糖序列、私人 PDF、姓名或身份、令牌、飞书密钥、OAuth 凭据、配对材料以及私人实验证据。

演示用固定数据必须为合成数据或已经明确去标识化的数据。

## English

## Core rule

Group context and private BodyOS context remain separated.

## Group may contain

- shared expert knowledge
- public check-in
- public challenge
- explicitly shared completion result

## Private BodyOS may contain

- Apple Health derived metrics
- CGM
- HRV
- sleep
- InBody
- Meal Event
- Body Check
- experiment
- Personal Body Model

## Never commit real health evidence

Do not commit:

- real HealthKit exports
- real glucose series
- private PDFs
- names / identities
- tokens
- Feishu secrets
- OAuth credentials
- pairing artifacts
- private experiment evidence

Demo fixtures must be synthetic or explicitly de-identified.
